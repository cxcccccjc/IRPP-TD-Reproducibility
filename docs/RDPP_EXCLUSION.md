# RDPP-TD comparison-code exclusion

The numerical RDPP-TD comparison in the manuscript was obtained by running the
code package supplied by the original RDPP-TD authors in an isolated
environment. The authors' privacy and security statement does not permit that
package to be redistributed as part of this artifact.

Accordingly, this repository contains no RDPP-TD implementation, dedicated
experiment driver, plotting-input file, or derived source copy. The paper may
report the independently obtained comparison values, but repository-local RQ1
reruns and Fig. 4(d) regeneration omit the RDPP-TD point.
