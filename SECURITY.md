# Security policy

This repository is a research artifact. Do not use the experimental contracts,
cryptographic wrappers, local PBFT deployment, or generated credentials in a
production system.

The tracked tree must not contain passwords, access tokens, node private keys,
TLS private keys, account key stores, or production data. FISCO BCOS setup
scripts generate disposable local credentials outside the repository. Report a
suspected disclosure privately to the repository owner before opening a public
issue.
